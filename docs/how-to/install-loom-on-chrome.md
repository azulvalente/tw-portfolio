# How to Install Loom on Google Chrome

Loom is a tool designed to create videos. With a few simple steps, you can record a tutorial, record yourself, or capture any type of video you want.

You can use Loom as a desktop application or install it as a Google Chrome extension. This guide covers the steps to add the extension to Chrome.

## Prerequisites

- Google Chrome installed on your computer

## Steps

1. Open Google Chrome and go to the [Chrome Web Store](https://chromewebstore.google.com/).
2. In the search bar, type **Loom** and press Enter.
3. Look for the official Loom extension — it has a purple logo and the description "Screen & Video Recording." Make sure it's published by "Loom" to avoid fake extensions.
4. Click the extension, then click **Add to Chrome**.
5. A confirmation popup will appear. Click **Add extension** to confirm.
6. Chrome may prompt you to allow camera, microphone, and screen-sharing permissions. Click **Allow** for each one to enable full recording functionality.

!!! tip
    If you don't see the Loom icon in your toolbar after installing, click the puzzle-piece icon next to the address bar, find Loom, and click the pin icon to keep it visible for easy access.

7. Click the Loom icon in your toolbar and sign in with your existing account, or sign up for free if you're new to Loom.

## Verification

Once signed in, click the Loom icon again — you should see options to record your screen, camera, or both. If this menu appears, the installation was successful.
